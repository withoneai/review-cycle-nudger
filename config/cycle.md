# Review cycle policy

The nudger reads this file verbatim, both the parts the code parses and the parts Claude reads. Edit it, not the code.

## When to nudge

Nudge window: 7 days
Started at: 60 words

A review is nudged when its deadline is inside the nudge window and the manager has written fewer words than the "started at" number. The status column is not trusted on its own: a review marked Drafting with nothing in it is still empty. A review marked Submitted is never nudged, whatever its length.

## Template lines

These lines come from the review template. They are not the manager's words and never count toward "started".

- Overall
- What went well this cycle
- Where to grow next cycle
- Goals from last cycle
- Rating
- Write two or three sentences on the overall cycle.
- Name one or two specific things, with an example.
- One concrete area, and what support looks like.
- How did each goal from the goals doc land?
- Meets / Exceeds / Below

## How the nudge reads

- It goes to a manager who is busy, not negligent. No guilt, no "friendly reminder", no exclamation marks.
- It opens with the deadline as a date, and how many reviews are still empty for them.
- For each report, it hands the manager a head start: how each goal in that person's own goals doc landed, quoted from the doc itself. The point is that the first paragraph is half written before they open the page.
- If the goals doc is missing or says nothing usable, say so plainly and suggest the manager starts from the "What went well" section instead. Never guess at a goal.
- It never rates the person, never suggests a rating, and never says anything about performance the goals doc does not say.
- Plain text, short, no em dashes or en dashes.
